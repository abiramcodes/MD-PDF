# Markdown to PDF Backend

This is the NestJS backend service for the MD-to-PDF application. It exposes an API to convert a given markdown string into a PDF file using Puppeteer.

## Running the Project Natively

### Prerequisites

- [Node.js](https://nodejs.org/) (v20 or later recommended)
- [npm](https://www.npmjs.com/)

### Installation

```bash
npm install
```

### Running the application

```bash
# development mode with watch
npm run start:dev
```

The application will be running on `http://localhost:3000`.
